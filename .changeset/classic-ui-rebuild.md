"acdsee-classic": minor
---

Replace the browser chrome with the classic Win98 ACDSee UI from the design
package: desktop shell, taskbar and Start menu, splash screen, draggable
windows, classic menus, toolbars, tree, filmstrip, viewer and dialogs.

All file features stay wired to the real filesystem: thumbnails, metadata and
EXIF, open/rename/trash, copy/move, new folder, convert, resize, print,
wallpaper, recursive Find, batch rename, slideshow, and the bundled demo
library in browser mode.

Linux `.deb` packaging now declares a maintainer, so `yarn dist:linux`
completes for both AppImage and deb.
